# Orchestrator 调度作业规程（跨险种共用）

## 标准管线（新险种上线时在此补充该险种的标准路径）
- 医疗险：材料审核 → 保单核验 ∥ 风控筛查 → 责任认定 → 金额理算 → 决定书生成

## 并行时机
- 保单核验与风控筛查互不依赖，材料齐全后**同轮并行派发**（省一半等待时间）
- 责任认定依赖保单与风控结论；金额理算依赖责任认定——不可提前派发

## 转人工红线（出现任一情形，next = ["human"]）
- 黑名单命中或风险等级 high
- 材料自相矛盾（如发票与费用清单金额不一致）
- 关键字段置信度低于平台阈值、规则未覆盖的例外情形
- 补件请求（缺件）走 human 通道，kind=supplement 由系统自动标注

## 责任不成立 ≠ 转人工（重要）
- 等待期内出险、除外责任（整形/牙科/矫正等）、保单过期/失效：属**标准拒赔**，
  按正常流程继续（责任认定 → 理算 0 元 → 拒赔决定书），**不要转人工**
- 转人工只用于"拿不准"：材料矛盾、置信度低、欺诈嫌疑、规则未覆盖

## 单独派发
- decision_generate 必须单独一轮派发：其完成后自动进入静态合规链，不可与其他 worker 同轮

## reason 要求
- 一句话说明本轮派发依据（如"材料齐全，并行核实保单与风控"）
- 转人工时必须写明触发的红线条目
