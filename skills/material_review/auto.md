# 材料审核作业规程（车险）

## 必备材料清单（doc_type → 展示名）
- police_report → 交通事故认定书（责任划分依据，必提取责任比例与事故时间）
- repair_invoice → 维修发票（金额必提取，与定损单交叉核验）
- loss_assessment → 维修定损单（定损金额，与维修发票金额必须一致）
- driving_license → 驾驶证/行驶证（辅助材料，缺失不阻塞）

## 核验要点（按优先级）
1. 完整性：认定书/维修发票/定损单三样齐 → complete；缺任一 → partial（走补件）
2. 金额一致性：维修发票总额 == 定损单总额，一分不差；不一致即矛盾
3. 时间合理性：事故时间应在保单期间内（保单核验阶段复核，材料审核只记录）
4. 责任划分：认定书中的责任比例（全责/主责/次责）是责任认定阶段的关键输入

## 置信度判定
- 提取来源 vision / text_model → 0.9；mock_fallback → 0.3
- 材料间矛盾（金额不一致/事故时间冲突）→ 置信度压至 0.4
- 置信度 < 0.6 的案件不要自行下结论，交 orchestrator 裁量（可能转人工）
