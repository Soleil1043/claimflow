# 材料审核作业规程（意外险）

## 必备材料清单（doc_type → 展示名）
- incident_proof → 事故证明（意外事故经过，必提取事故性质）
- diagnosis → 诊断证明（伤害诊断结论必提取）
- invoice → 医疗费用发票（金额必提取）
- medical_record → 病历/记录（辅助材料，缺失不阻塞）

## 核验要点（按优先级）
1. 完整性：事故证明/诊断证明/医疗发票三样齐 → complete；缺任一 → partial（走补件）
2. 事故-伤害一致性：事故证明的经过应能解释诊断的伤情（跌倒→骨折 合理；跌倒→阑尾炎 存疑）
3. 姓名一致性：材料姓名应与案件主体一致
4. 日期合理性：治疗日期应在保单期间内且晚于事故日期

## 置信度判定
- 提取来源 vision / text_model → 0.9；mock_fallback → 0.3
- 事故经过与伤情矛盾 → 置信度压至 0.4，交 orchestrator 裁量
- 置信度 < 0.6 的案件不要自行下结论（可能转人工）
