# 材料审核作业规程（财产险）

## 必备材料清单（doc_type → 展示名）
- incident_proof → 事故证明（警方/消防出具，必提取事故性质与发生时间）
- loss_list → 损失清单（受损财产明细与估损金额）
- purchase_receipt → 购置凭证（受损财产的购置发票/收据，金额必提取）
- property_photo → 现场照片（辅助材料，缺失不阻塞）

## 核验要点（按优先级）
1. 完整性：事故证明/损失清单/购置凭证三样齐 → complete；缺任一 → partial（走补件）
2. 明细一致性：损失清单条目应与购置凭证能对上（同一财物口径）
3. 事故性质：火灾/暴雨/盗抢等事故性质决定是否在保障范围（责任认定阶段判定）
4. 时间合理性：事故时间应在保单期间内（保单核验阶段复核）

## 置信度判定
- 提取来源 vision / text_model → 0.9；mock_fallback → 0.3
- 清单与凭证明显对不上（财物/金额冲突）→ 置信度压至 0.4
- 置信度 < 0.6 的案件不要自行下结论，交 orchestrator 裁量（可能转人工）
