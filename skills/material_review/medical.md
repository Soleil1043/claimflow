# 材料审核作业规程（医疗险）

## 必备材料清单（doc_type → 展示名）
- invoice → 医疗发票（金额必提取，与费用清单交叉核验）
- diagnosis → 诊断证明（诊断结论必提取）
- cost_list → 费用清单（明细金额，与发票金额必须一致）
- medical_record → 病历/记录（辅助材料，缺失不阻塞）

## 核验要点（按优先级）
1. 完整性：发票/诊断证明/费用清单三样齐 → complete；缺任一 → partial（走补件）
2. 金额一致性：发票总额 == 费用清单总额，一分不差；不一致即矛盾
3. 姓名一致性：各材料患者姓名应与案件主体一致（或为其法定关系人，就医场景允许）
4. 日期合理性：治疗日期应在保单期间内（保单核验阶段复核，材料审核只记录）
5. 自费/乙类标识：费用清单中"自费""乙类自付"金额是部分责任理算的关键输入

## 置信度判定
- 提取来源 vision / text_model → 0.9；mock_fallback → 0.3
- 材料间矛盾（金额不一致/姓名冲突/诊断与类型不符）→ 置信度压至 0.4
- 置信度 < 0.6 的案件不要自行下结论，交 orchestrator 裁量（可能转人工）
