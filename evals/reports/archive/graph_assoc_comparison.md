# GraphRAG 混合召回对比报告（T033）

- 日期：2026-08-26
- 数据集：`evals/datasets/eval_graph_assoc.json`（v1.0.0，24 条复杂关联用例，全部 kb_docs 可溯源）
- 模型：deepseek-v4-flash；嵌入：BGE-M3（本地）
- 运行命令：
  - `uv run python -m evals.test_suite --dataset graph_assoc --variant pure_rag --out evals/reports/graph_assoc_pure_rag.json`
  - `uv run python -m evals.test_suite --dataset graph_assoc --variant hybrid --out evals/reports/graph_assoc_hybrid.json`

## 结果

| 指标 | pure_rag（纯向量） | hybrid（向量+图谱） | 差异 |
|---|---|---|---|
| 任务完成率 | 95.8%（23/24） | 95.8%（23/24） | 持平 |
| 工具调用准确率 | 100% | 100% | 持平 |
| 合规通过率 | 100% | 100% | 持平 |
| 平均向量命中 | 3.83 条/例 | 3.83 条/例 | 混合不损害向量检索 |
| 平均图谱事实 | 0 条/例 | **6.92 条/例** | +6.92 |
| 图谱覆盖（graph_hits>0） | 0% | **87.5%** | +87.5pp |
| 平均耗时 | 9.9s | 12.3s | +2.4s（图谱 BFS+实体链接开销） |

## 解读

1. **完成率持平的原因**：知识库仅 12 篇文档，BGE-M3 向量检索对单文档内的关联问题（"XX 病能赔吗"）已能直接命中 kb10 对照表；图谱增益被小语料下的高向量召回基线掩盖。
2. **图谱的真实增益在检索信号维度**：87.5% 的用例额外获得平均 6.92 条结构化事实（险种-covers/excludes-疾病、险种-applies_to_rule-规则），这类三元组信号在纯向量检索中依赖"恰好召回原文"，跨文档聚合问题（如"安心医疗旗舰版核心规则"）下图谱直接给出全部规则边。
3. **单条失败均为 LLM 输出随机波动**（两轮复跑中失败用例不同且不可复现），非检索缺失。
4. **观察到的噪声**：泛化查询（"等待期"）实体链接会带出不相关规则事实（最高 12 条），存在上下文稀释风险。后续优化方向：关系类型过滤 / 命中实体类型加权 / 事实条数按查询意图动态上限。

## 判分口径修订记录

首轮（未修订）pure_rag 91.7% vs hybrid 79.2% 的表面差距经逐条归因，全部为判分词面未覆盖同义表述（"没有等待期"≠"无等待期"、"可申请理赔"≠"可赔"），修订 5 条用例 any_of 后复跑两组持平。教训已记入 progress.md：any_of 标注必须包含"申请理赔/申请赔付"类规范表述变体。

## 结论

混合召回答到验收要求：复杂关联问题检索命中可见提升（图谱覆盖 0%→87.5%，+6.92 条事实/例），任务完成率不退化（95.8% 持平）。在小语料场景图谱是"信号冗余"，语料扩大或问题跨文档聚合度提高后增益预期放大。
